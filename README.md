# TicketEase AI Backend

## Tech Stack
Java 21, Spring Boot 3.x, Spring Security, Spring Data JPA, PostgreSQL, Redis, Maven, JWT, WebSocket, Swagger, Razorpay, Docker

## Modules
User, AI Trip Planner, Event, Stadium Seat, Transport, Hotel, Restaurant, Booking, Payment, Notifications, Resale

## Run
docker compose up -d
mvn spring-boot:run
